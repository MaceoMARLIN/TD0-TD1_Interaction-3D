# TD0_Interaction-3D

📌 Project Overview

This project was developed as part of a practical assignment focused on 3D object selection, manipulation, interaction, and animation using the Unity engine.

The main objective is to create an interactive environment where the user can interact with 3D objects using a laser-based system.

🎯 Features
🔦 Laser Interaction System
A laser appears when the left mouse button is pressed
The laser allows interaction with objects in the scene
🧱 3D Object Selection & Manipulation
Objects can be targeted using the laser
Interactive feedback when objects are selected
🎬 Animation System
Objects react dynamically when interacted with
Animations triggered through user interaction
🖱️ User Input Handling
Left click → activates the interaction laser
Real-time interaction with the environment
🛠️ Technologies Used
Unity
C# scripting
Unity Input System / Input Manager

🎮 Controls
Action	Input
Activate laser	Left mouse click
Interact with objects	Aim with laser
